# 🔒 Fundamentals of Cybersecurity

## 📘 What is Cybersecurity?
Cybersecurity is the practice of protecting systems, networks, and programs from digital attacks. These cyberattacks are typically aimed at:
- Accessing, changing, or destroying sensitive information
- Extorting money from users (ransomware)
- Interrupting normal business processes

## 🧱 Core Principles (CIA Triad)
1. **Confidentiality** – Ensure only authorized users can access data
2. **Integrity** – Ensure data is accurate and unaltered
3. **Availability** – Ensure systems and data are available when needed

## 🔐 Key Security Concepts
- **Authentication vs Authorization**: Verifying identity vs granting access
- **Least Privilege**: Users/systems should only have the permissions they need
- **Defense in Depth**: Multiple layers of security controls
- **Security by Design**: Build security into the architecture from the start
- **Risk Management**: Identify, evaluate, and mitigate security risks

## 🚨 Types of Threats
- **Malware** (viruses, worms, Trojans, ransomware)
- **Phishing** (email/social engineering attacks)
- **Denial of Service (DoS)** / **DDoS** attacks
- **Man-in-the-Middle (MitM)** attacks
- **Insider Threats**

## 🛡️ Common Security Controls
- Firewalls, Antivirus, IDS/IPS
- Multi-Factor Authentication (MFA)
- Patch Management
- Encryption (Data at rest & in transit)
- Security Monitoring (SIEM tools)

## ✅ Best Practices
- Keep software updated
- Use strong, unique passwords (consider password managers)
- Enable MFA everywhere possible
- Backup data regularly
- Conduct regular security training and awareness
