# Cloud & Cybersecurity Knowledge Repository

Welcome to my personal learning repository on **Cloud Security**, **Cybersecurity**, and **DevSecOps**. This space is a structured collection of notes, practical insights, tools, and best practices that I’ve gathered throughout my continuous learning journey.

## 🎯 Objective

This repository aims to:

* Serve as a reference for preparing for certifications, interviews, and real-world implementation.
* Reinforce foundational concepts and practical skills in cybersecurity and cloud environments.
* Provide hands-on notes and guides across platforms like Azure, AWS, GCP, and Kubernetes.
